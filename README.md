# Shooter

## Цель проекта

Запрограммировать игру “Шутер”, было выделено 4 занятия. В игре должен быть игрок и враги.
Игрок должен стрелять пулями при нажатии кнопки “Space”, враги при столкновении с пулями пропадают и к счётчику прибавляется одно очко.

## Реализовано

5 спрайтов
1 фоновая музыка и 1 звуковой эффект
Класс GameSprite(Наследник от модуля Sprite)
4 класса под Игрока, Врага, пулю и астероид
Игровой цикл
Есть фоновая музыка и звуки выстрелов.
Есть перезарядка патронов.
Хп игрока
